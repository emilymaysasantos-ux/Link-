## 📰 Sobre o Projeto

Este projeto foi desenvolvido como parte da avaliação de Educação Digital do Colégio Frederico Guilherme Giese.

A proposta consiste na criação de uma página de notícias profissional, responsiva e adaptada para diferentes tamanhos de tela. A notícia aborda o tema **Vampirinhos**, apresentando uma versão divertida e amigável dos tradicionais personagens de histórias de fantasia.

## 💻 Tecnologias Utilizadas

- HTML5 — estrutura e conteúdo da página
- CSS3 — cores, layout, responsividade e estilização
- JavaScript — inserção automática da data de publicação
